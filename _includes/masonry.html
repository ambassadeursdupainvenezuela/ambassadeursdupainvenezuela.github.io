{%- comment -%} Shared masonry layout engine. Any container with `data-masonry-grid="true"` and class `masonry-grid` (items marked `masonry-grid-item`, see styles.html) gets its items' `grid-row-end` spans computed from their real rendered height, so items of different heights pack together without gaps. Works for any number of grids on the same page (e.g. a photo gallery and a blog cards grid can both live on index.html). {%- endcomment -%}
